# Sendi's Data Story

Create a modern, professional personal portfolio website for Sendi Wildanto, an Information Systems graduate focused on Data Analytics, Business Intelligence, and System Analysis.

IMPORTANT DESIGN DIRECTION:

Do NOT create a dark developer portfolio.

Do NOT use a black/dark background as the primary theme.

The current portfolio feels too dark and generic, so redesign it from scratch with a bright, clean, premium, recruiter-friendly visual identity.

The website should feel like a combination of:

- modern data analyst portfolio

- professional consulting website

- clean SaaS dashboard

- editorial personal portfolio

TARGET AUDIENCE:

Recruiters, hiring managers, Data Analyst / BI / System Analyst teams, and technology companies.

PRIMARY VISUAL STYLE:

- Light background

- White and very light blue-gray surfaces

- Deep navy text

- Blue as the primary accent

- Subtle cyan/teal accents where appropriate

- Large clean typography

- Generous whitespace

- Rounded cards, but not overly rounded

- Thin borders and very subtle shadows

- Minimal gradients

- Professional, mature, and polished

- Avoid excessive animations

- Avoid overly flashy "developer" aesthetics

- Avoid neon colors

- Avoid excessive glassmorphism

- Avoid huge text that dominates the page

COLOR DIRECTION:

Primary: deep navy / professional blue

Accent: modern blue

Secondary accent: cyan/teal

Background: #F7F9FC or similar

Cards: white

Text: dark navy

Muted text: slate gray

The website should look excellent on both desktop and mobile.
